#  Arena Copa-Flutter

Aplicativo desenvolvido em Flutter para acompanhar informações relacionadas à Copa do Mundo.

##  Funcionalidades

- Tela de Login
- Tela de Cadastro
- Página Inicial
- Menu Lateral de Navegação
- Visualização de Jogos por Grupos
- Informações dos Jogos
- Área de Perfil
- Seção de Figurinhas
- Seção de Produtos

##  Tecnologias Utilizadas

- Flutter
- Dart
- Material Design

##  Estrutura do Projeto

```text
lib/
├── main.dart
├── login.dart
├── cadastro.dart
├── inicio.dart
├── jogos.dart
└── ...
```

##  Como Executar

1. Clone o repositório:

```bash
git clone (https://github.com/Livlivm/Arena_copa.git)
```

2. Entre na pasta do projeto:

```bash
cd Arena_Copa
```

3. Instale as dependências:

```bash
flutter pub get
```

4. Execute o projeto:

```bash
flutter run
```
